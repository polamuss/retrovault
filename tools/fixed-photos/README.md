# Photos fixes publiques

Depuis une fiche matériel, choisir une photo, préparer la publication pour tous, puis déposer le JSON généré dans ce dossier et valider le commit. Seules les photos créées par le déposant ou dont il possède les droits de redistribution sont acceptées. Le nom du fichier est déterministe et un remplacement écrase la précédente photo. Le build transforme la photo en AVIF et la privilégie par rapport aux sources automatiques. Supprimer le JSON pour rétablir la recherche habituelle. Ne jamais déposer de photo privée ou de jeton GitHub.
